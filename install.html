MCReportSystem

Installation and configuration

Get the plugin running in minutes. You need Java 17+, Paper/Spigot 1.20.1 and a Discord bot.

Steps

  1. Download the latest JAR from the repository's Releases section.
  2. Copy it to the plugins/ folder and restart the server.
  3. Edit plugins/MCReportPlugin/config.yml with the bot token and Discord IDs.
  4. Restart again and verify that the bot is connected and has the required permissions.

Bot permissions

The bot needs permission to send messages, view channels, manage channels, embed links, send embeds and attach files.

Protect your token

Never publish the bot token or commit it to the repository. If it leaks, revoke it immediately in the Discord Developer Portal.

Updates on managed hosts

When auto-update is enabled, the new JAR is downloaded as MCReportPlugin-new.jar. Stop the server from the host panel before replacing the loaded file; do not use /reload.
