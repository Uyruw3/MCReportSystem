MCReportSystem

Instalación y configuración

Pon el plugin en marcha en unos minutos. Necesitas Java 17 o superior, Paper/Spigot 1.20.1 y un bot de Discord.

Pasos

  1. Descarga el JAR de la última versión desde la sección Releases del repositorio.
  2. Copia el archivo en la carpeta plugins/ y reinicia el servidor.
  3. Edita plugins/MCReportPlugin/config.yml con el token del bot y los IDs de Discord.
  4. Reinicia de nuevo y comprueba que el bot esté conectado y tenga los permisos necesarios.

Permisos del bot

El bot necesita enviar mensajes, ver canales, gestionar canales, insertar enlaces, enviar mensajes embebidos y adjuntar archivos.

Protege tu token

No publiques el token del bot ni lo subas al repositorio. Si se filtra, revócalo inmediatamente desde el portal de desarrolladores de Discord.

Actualizaciones en hosts gestionados

Si activas la auto-actualización, el nuevo JAR se descarga como MCReportPlugin-new.jar. Detén el servidor desde el panel antes de reemplazar el archivo cargado; no uses /reload.
